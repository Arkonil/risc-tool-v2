## High-Level Workflow

The typical workflow in the tool involves the following steps:

1.  **Setup/Home**: Decide whether to start a new project or restore an entire previous session from a JSON archive.
2.  **Import Data**: Load your CSV or Excel datasets and define variable roles.
3.  **Explore & Clean**: Use the Data Explorer to analyze variable strength (IV) and handle outliers.
4.  **Define Metrics**: Create custom calculations to evaluate risk performance.
5.  **Subset Data**: Build filters to isolate specific populations.
6.  **Configure Tiers**: Define risk segments and annualization scalars.
7.  **Run Iterations**: Combine filters and metrics to simulate different risk strategies.
8.  **Compare & Export**: Analyze results in the Summary view and export to SAS or Python code.
